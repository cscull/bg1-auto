Setup Instructions

Safari (iPhone)

  1. Bookmark any page (e.g. this one)
  2. Edit the bookmark — change the name to BG1
  3. Replace the URL with the bookmarklet code above
  4. Navigate to a Disney page below, then open the bookmark

Chrome (Android)

  1. Copy the bookmarklet code above
  2. Bookmark any page, name it BG1
  3. Edit the bookmark and paste the code as the URL
  4. Navigate to a Disney page below, type BG1 in the address bar, and tap the bookmark suggestion
